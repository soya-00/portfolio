# Accessibility, degradation and what is not built

A record of what this page does when something is missing: scripting, colour
vision, a pointing device, a wide screen, or an appetite for motion. It also
records what was deliberately not built, since an omission a reader cannot
see is indistinguishable from an oversight.

Everything below was measured against the built page in Chromium, not
asserted from the source.

## The standing rule

Anything conveyed by colour is also conveyed by something else. This is the
portfolio's own non-negotiable, inherited from BLOC's design system, and the
charter arrives at the same rule independently. In practice every state in
every module carries three channels: a glyph, a fill or pattern, and a written
label. Colour is the last of the three and never the only one.

## Degradation without JavaScript

Measured with scripting disabled:

| Check | Result |
|---|---|
| Words of prose in the page body | 14,383 |
| Citations present and openable | 110 |
| Modules rendered | 5 |
| Textual equivalents reachable | 5 |
| Controls that would do nothing, left visible | 0 |

The page is prerendered at build time and hydrated on top, so the prose is in
the HTML rather than assembled by the browser. `scripts/prerender.mjs` exits
non-zero if a page would ship with an empty root, so this cannot regress
silently.

Citations use `:target` rather than scripting. A closed panel is
`display: none`, so its contents are out of the tab order; verified by
attempting to focus a closed panel's close link, which the browser refuses.

Controls that need scripting carry `js-only` and are hidden without it.
Panels that collapse behind such a control carry `chain-detail` or
`js-hidden` and stand open when there is no control to collapse behind them.

## Motion

Every animated figure checks `prefers-reduced-motion` and, when it is set,
renders its finished frame with **no transition and no delay**. An earlier
build set the end value but left the stagger delay in place, which still
animated the figure in; that was a defect and is fixed. Verified by measuring
element opacity 120 ms after scroll, before any transition could have run.

No motion encodes anything. Every figure holds the same information before
and after its animation.

## Per module

### The document, and what may be shown of it

A table plus a stat pair, deliberately not a chart. Nineteen distinct legal
grounds is past the point where a categorical palette stays separable, and
thirteen against fourteen is a number rather than a plot.

Narrow screens: the table scrolls inside its own container; the page body
never scrolls sideways.

### A recording in law, jurisdiction by jurisdiction

A 14 × 6 categorical grid in four views. State is carried by glyph, fill
pattern and label. `NOT-DOCUMENTED` takes a hatch, an em rule and the words
themselves, so it can never read as a documented negative — the failure the
section names in advance.

`validate_palette.js` does not apply: no categorical hue set exists to
validate. That is an exemption with a reason, not a check skipped.

The map draws no coastlines and no borders. A filled world map would put
roughly a hundred and eighty unstudied countries on screen in some resting
state, and a reader would take that state as a finding. There is none. Two
records are not territories and sit in a band beneath the map instead of on
it.

Narrow screens: the grid and the map scroll inside their containers.

### From a recording to a discipline

A directed diagram. An arrow reads as causation whether or not anyone claimed
it, which is the one conclusion the charter forbids the piece from reaching,
so the figure answers it three ways: the second strand is drawn, the open
question spans the chain inside the figure, and the unestablished claim is
flagged on its node.

Nodes are not on a metric time axis. Two dates overlap to the month and one
carries only a year, so a measured axis would assert an ordering the record
does not establish.

### A census of failures

A unit chart on one side and nothing on the other. The unrecorded population
gets no number, no area and no boundary, because nothing in the corpus
measures it and any extent drawn would be a ratio no source supports. On wide
screens the frame is open on that side.

The loop ring carries no duration and no amplitude. It is not a waveform and
derives from nothing that was recorded.

### Five candidates, ranked by documentation

The one ordinal scale in the piece, and therefore the one justified colour
ramp. Computed rather than eyeballed:

```
node validate_palette.js "#836949,#a3835c,#b69c7c,#c8b59d" \
  --ordinal --mode dark --surface "#161613"

Lightness monotone      PASS
Adjacent dL             PASS  all gaps >= 0.06
Dim-end contrast        PASS  3.52:1 vs surface
Single hue              PASS  spread 2 degrees
```

Bar length and a filled-block glyph carry the same value, so the ramp is
reinforcement and not the channel.

One candidate sits off the scale with no bar. A question the record cannot
answer is not a weaker grade of evidence, and ranking it last would say
something false about it.

## Structure

| Check | Result |
|---|---|
| `<main>` landmarks | 1 |
| `<h1>` | 1 |
| Heading-level jumps | 0 |
| Images without `alt` | 0 |
| `svg[role="img"]` without an accessible name | 0 |
| Buttons without an accessible name | 0 |
| Tables without a `<caption>` | 0 |
| Live regions | 1, central |
| Scroll containers unreachable by keyboard | 0 |
| Text below 4.5:1 against its background | 0 |
| axe-core violations, WCAG 2.1 A + AA | 0 |

The last three are measured, not asserted: axe-core runs against all five built
pages, and it read 709 violating nodes before this pass. 697 of those were
contrast. Secondary text is written as `muted-foreground` at 50–85% opacity,
and the token sat at 62% lightness, which put every tier below `/75` under the
floor — worst on the 10px tracked labels that were already the hardest thing on
the page to read. The token is now 72%, and the two tiers that still failed at
that lightness were stepped up to `/75`.

Every module announces view changes through one shared live region defined in
the shell, rather than each module declaring its own.

## Reflow

At 640 CSS pixels the page body does not scroll horizontally. Wide content —
the jurisdiction grid, the map, the chain, the corpus comparison — scrolls
inside its own container, which is where a horizontal scroll belongs.

That was half the claim. A container that only a mouse can push is not
reachable, whatever the reflow behaviour, and until now none of these could
take focus: the arrow keys had nothing to act on and Safari never focuses a
scroller on its own. Each one is now a focusable region, named from the
caption or figcaption already printed beside it, so it announces as something
rather than as "region".

The tab stop is withdrawn when the content fits. Most of these boxes overflow
only on a narrow window, and a stop landing on a box with nothing to scroll is
an empty press. It is present in the prerendered markup and removed by script
once measured, so the no-JS reader keeps the access and only loses the tidying.

Two scrollers are deliberately left alone. The navigation strip and the project
tree are built from links, so tabbing through their contents already scrolls
them into range; a wrapper stop there would land on nothing.

## Textual equivalents

Every module ships one, in the same commit as the module. They are peers and
not fallbacks: for a citation-heavy piece a real share of the primary
audience will prefer the prose outright. Each is reachable three ways — its
own disclosure control, a direct link to its id, and the global alternatives
setting, which swaps every module for its equivalent at once.

## Crew names

Zero appear on any reader-facing surface. `grep` across `dist/` for a rank
followed by a capitalised word, and for two adjacent capitalised words,
returns nothing. Roles only: Captain, First Officer, Flight Engineer,
Controller.

## What is not built, and why

**The annotated transcript.** The brief calls it the centrepiece. There is no
`data/transcripts/` directory, no utterance records, no annotation categories
and no per-utterance provenance, and the schema defines no transcript record
type. `accidents.json` carries a licence flag, not content. Building it would
have meant writing the transcript, which is the one thing the charter forbids
absolutely. The content already discloses this: transcript-level treatment is
available for four cases and not the other two, and the availability tracks
the licensing policy of the issuing state.

**The adoption timeline.** `crm-timeline.json` does not exist. The nearest
data is `crm_mandate_first_date`, of which five of fourteen are dated and
nine are `NOT-DOCUMENTED`. The module's stated purpose was to show lag and
reversal across jurisdictions; five points cannot show a lag pattern, and
plotting them would render nine absences as an empty timeline. The adoption
chronology survives in prose with document numbers at every step.

**Four dimensions of the corpus comparison.** Outcome, phase of flight,
cockpit language, and whether coordination was cited each have no sourced
schema field. Deriving outcome from a zero fatality count would misclassify
the 1989 case that is canonically a coordination success and killed 112
people. Any dimension without a sourced field is not shown, and is named as
omitted rather than approximated.

## What is measured on every build

```
npm run validate      # the corpus gate, R1 to R12
npm run timing        # core path reading time
npm run build         # typecheck, bundle, prerender, drift
node scripts/check-content.js   # rendered prose against content/, word for word
```

The drift check compares all 18 documents against the rendered page and fails
on any divergence, so the prose on screen cannot drift from the corpus
without the build going red.

## Left for a manual pass

A screen-reader pass by someone who has not been told the equivalents exist.
Everything above is machine-measured, and a machine cannot tell whether the
equivalents are findable by someone who does not already know their names.
